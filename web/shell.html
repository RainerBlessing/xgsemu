How to play

Pick a program from the list, or load your own .hex / .obj file for the XGameStation Micro Edition. Click the picture once so the page receives your keystrokes and the browser allows sound.

KeyJoystick
↑ ↓ ← →Move (up, down, left, right)
Space or CtrlFire button
F5Reset the running program (the Reset button does the same)
MMute / unmute the sound

On a Mac, Ctrl+arrow keys may switch desktops, so use Space to fire. For full screen use the button above.
